# LyriFind — Week 3 Testing and Debugging
This package adds a focused testable song-utility module to your Week 2 LyriFind project.

## Run
Requires Node.js 18+ (20 LTS recommended). Open terminal in `backend` and run:
`npm test`
No database or third-party npm packages are needed for these unit tests.

## Contents
- `backend/src/songUtils.js`: search, language filtering, and validation functions.
- `backend/tests/songUtils.test.js`: 15 unit tests using Node's built-in test runner.
- `backend/DEBUGGING_REPORT.md`: seven bug scenarios, root causes, fixes, and lessons.
- `backend/TEST_RESULTS.md`: fill in after running the tests.

Copy these files into the same Week 2 GitHub repository (keep the existing backend files). This is a focused test module, not the entire Week 2 app. Do not claim a measured 80% code coverage without running a coverage tool. Update the result record with actual terminal output.
